# Circus Chuck art and review evidence

`art.js` is the hand-painted palette-letter source, including clown run/jump/tumble/cheer poses, lion and horse strides, monkeys, balls, rings, pots, springs and trapezes.

From the repository root run `node game/tools/art/circus/embed.cjs` after editing sprites. With the game served and RA_URL set, run `node game/tools/test/circus-art.cjs` to render `sheet.png` in Chromium.

`review/` preserves the checked stage screenshots at all three requested sizes, the animation contact sheet, split screen and test results. The dated work report is `.codex-report-circus.md` at repository root. No generated assets depend on Python.
